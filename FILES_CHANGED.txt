ENVIRONMENT SETUP
=================

Required .env variables:
  APIFY_API_TOKEN=your_token
  APIFY_FB_ADS_ACTOR=curious_coder/facebook-ads-library-scraper
  ANTHROPIC_API_KEY=your_key
  CLAUDE_MODEL_FAST=claude-haiku-4-5-20251001
  URL_TO_ADS_AD_LIBRARY_COUNTRY=AE

Start the enrichment worker:
  node workers/urlToAdsEnrichWorker.js

Start the API server:
  npm start


API RESPONSE CHANGES
====================

GET /studio/url-to-ads/scan/{id}

NEW FIELDS ADDED TO RESPONSE:
  
  scan.apifyCompetitorAds: Array
    - Per-competitor results with normalized ads
    - Each ad has intelligence enrichment
    - Sorted by relevance, top 20 per competitor
  
  scan.competitorAdsSummary: Object
    - totalAds: number
    - winners: number
    - topPatterns: array of {pattern, count}
    - spendingHeavyweights: array of competitor stats
    - errors: array of per-competitor errors
